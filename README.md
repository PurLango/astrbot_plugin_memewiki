# AstrBot 梗百科

面向 AstrBot 的本地梗百科插件。内置 6792 条网络梗、缩写和黑话词条，在用户询问梗或模型遇到陌生词时按需查询，避免硬猜。

## 功能

- `/梗 词语`：查询内置词库或当前群的自定义黑话
- `/黑话 词语 释义`：新增或更新当前群的黑话
- `/黑话 列表`：查看当前群的自定义黑话
- `/黑话 删除 词语`：管理员删除当前群的黑话
- `search_meme_wiki`：提供给模型的本地查梗工具
- 自动预查：仅在消息像是在问梗或只包含一个短词时查询；命中后只临时注入一条词条
- 可选的串子程度：控制模型玩梗时的语气尺度
- AstrBot 管理页面：搜索、新增、编辑、改名和删除词条
- 一键更新词库：从 `cnmeme.wiki` 公开接口补充新词条，不覆盖本地修改

## 安装

在 AstrBot 管理面板中选择“从链接安装”，填写：

```text
https://github.com/PurLango/astrbot_plugin_memewiki
```

插件要求 AstrBot `4.24.0` 或更高版本，不需要额外 Python 依赖。

安装后请确认当前配置文件允许使用本插件；若希望模型主动调用查梗工具，还需在人格能力中启用 `search_meme_wiki`。

## 配置

- `auto_prefetch`：是否自动识别并预查梗，默认开启
- `max_query_chars`：自动预查候选词的最大长度，默认 12
- `roast_enabled`：是否启用串子程度，默认关闭
- `roast_level`：玩梗尺度，范围 0–100

所有普通查询均在本地完成，不会把聊天内容发送给词库网站。群内自定义黑话保存在 AstrBot 的插件数据目录，不写入插件源码目录。

## 梗百科管理

入口：`AstrBot 管理面板 → 插件 → 梗百科 → 梗百科管理`。

管理页左侧用于搜索和选择词条，右侧可新增、编辑、改名或删除。点击“一键更新”后，插件会按更新时间检查 `cnmeme.wiki` 的最新公开词条，只下载本地尚未收录的新内容；同步期间可在页面查看进度。运行词库保存在 AstrBot 插件数据目录，源码包中的数据库仅用于首次初始化。

## 查询规则

插件依次尝试：群内自定义黑话、精确标题、别名、标题前缀、消息中包含完整标题，以及长度足够时的反向包含匹配。没有命中时不会向模型注入内容。
